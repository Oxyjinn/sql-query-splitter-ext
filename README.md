# SQL Query Splitter
Get all SELECT and TABLE from an SQL query. Making sure you got easier time documenting your works.

How to use:
1. Code -> Download ZIP.
2. Unzip the folder.
3. Go to your browser and click manage extensions.
4. Activate "developer mode".
5. Click "Load unpacked" and choose your folder.
6. Enjoy the extension.

How it works:
1. Copy your query.
2. Click the extension.
3. Paste your query.
4. Press the "Split & Format Query" button.

Tested on Chrome & Edge.
